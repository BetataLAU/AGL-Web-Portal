## 一、專案背景與核心目標

### 1.1 業務場景
航空貨運站操作員需將來自不同客戶、不同包裝類型（Carton / Pallet）的貨物，裝入特定型號的 ULD（集裝器，如 Q7-00、PMC、AKE 等）。ULD 具有**異形收角（Contour）**結構（如 Q7 從 96" 高度開始向內收窄），且每個航班同時使用多個 ULD。

### 1.2 核心痛點與目標
| 痛點 | 解決方案目標 |
|------|-------------|
| 手動配載耗時且依賴經驗 | 提供「自動演算法生成方案」與「人工拖拽微調」雙模式 |
| 多客戶貨物混載難以區分 | 以 HAWB/Customer 為單位，自動分配專屬色卡，3D 場景直觀區分 |
| ULD 異形收角導致超限風險 | 精確幾何建模 + 即時超限碰撞檢測（紅色警報） |
| 需同時管理多個 ULD 的整體配載 | 左側 ULD 清單 + 底部全局匯總欄，即時監控個體及總體 WT/V.W |
| 倉庫人員需按順序作業 | 生成「組裝流程動畫」，逐步展示裝載順序 |


## 二、理論基礎與演算法選型（給 AI 的明確指引）

> **此章節目的**：防止 AI 憑空創造無效演算法。必須明確指定理論方向。

### 2.1 問題定義
- 本系統的自動裝箱屬於 **離線（Offline）3D 多箱型裝箱問題（3D-MBSBPP）**，即所有貨物資訊在裝箱前已完全已知。
- **多目標優化函數**（依優先級排序）：
  1. **首要**：最大化各 ULD 的體積利用率（目標 ≥ 85%）
  2. **次要**：最小化使用的 ULD 數量
  3. **約束條件**：
     - 貨物不可重疊
     - 貨物不可超出 ULD 輪廓邊界（含收角斜面）
     - 重心（CoG）須落在飛行包線安全範圍內
     - 穩定性：重物不可壓輕物（除非輕物有足夠承重能力）

### 2.2 推薦演算法架構（兩階段）
| 階段 | 方法 | 說明 |
|------|------|------|
| **第一階段（構建初始解）** | **最大剩餘空間（Maximal Spaces）啟發式** + 貨物排序策略（按體積遞減 / 按重量遞減） | 快速生成可行初始解 |
| **第二階段（優化迭代）** | **混合遺傳演算法 + 大鄰域搜索（Hybrid GA-LNS）** | GA 負責全局探索，LNS 負責局部精細搜索，生成 Pareto 前沿的多組方案 |

### 2.3 實作參考
- 可參考開源專案 `enzoruiz/3dbinpacking`（Python）或 `bin-packing-3d`（JavaScript）的核心邏輯，但**必須針對航空 ULD 異形輪廓進行客製化改造**。
- 若效能成為瓶頸，可考慮將核心演算法以 **Rust 編譯為 WebAssembly**（如 `packme-wasm`）提升瀏覽器端運算效能。
- 演算法運算時須提供**進度條 + 取消按鈕**，避免瀏覽器卡死。


## 三、功能需求詳述

### 3.1 專案初始化與多 ULD 管理

#### 3.1.1 啟動嚮導
用戶進入系統後，首先顯示 **「ULD 配置清單」** 彈窗或面板，需填寫：
- `MAWB#`（主單號）
- `DEST`（目的站）
- **ULD 清單**（可動態增減行）：`序號` | `ULD 類型（下拉選擇）` | `數量`

#### 3.1.2 操作介面中的 ULD 管理
- **左側 ULD 清單**：顯示所有 ULD，每行包含：
  - `📦 Q7-01 [68%] 1,200kg / 3,500kg(V.W)`
  - 點擊任一 ULD，右側 3D 場景**立即聚焦**到該 ULD。
- **底部全局匯總欄（固定懸浮）**：
  - 總毛重 / 總體積重 / 總限載 / 整體裝載率
  - 若超限 → 瞬間變紅並閃爍警告
- **動態調整**：保留「➕ 追加 ULD」按鈕，允許中途新增容器。

---

### 3.2 貨物數據錄入（Shipment Input）

#### 3.2.1 主從結構（MAWB → HAWB/Customer → Items）
| 層級 | 欄位 | 說明 |
|------|------|------|
| MAWB | MAWB#, DEST | 頂層容器，對應一次航班/運單 |
| HAWB / Customer | HAWB#, Customer Name | **一個客戶對應一個 HAWB**，系統自動分配專屬**色卡（Color Code）** |
| Items | 長、寬、高、PCS、單件毛重 (KG)、Pack Type | 實際貨物 |

#### 3.2.2 包裝類型（Pack Type）
- **兩大類**：`PLT (Pallet)` 與 `CTN (Carton)`
- 現實中的桶/卷/掛衣，統一映射為此兩類，但可在備註中標註實際形態（3D 渲染時可做圓柱體佔位，但物理碰撞箱仍為長方體）。

#### 3.2.3 貨物分配
- 錄入時須指定該貨物歸屬於哪個 ULD（下拉選擇：「待分配 / ULD-1 / ULD-2 / ...」）。
- 若選擇「待分配」，點擊「自動裝箱」時系統會自動分配。

#### 3.2.4 錄入效率優化
- **複製上一行（Clone Row）**
- **從剪貼簿貼上（CSV Paste）**：支援從 Excel 複製多行數據，Ctrl+V 直接寫入表格
- **HAWB 模板繼承**：輸入 HAWB 前幾碼時自動聯想補齊客戶名稱及常用尺寸

---

### 3.3 重量與體積的智能化顯示（KG / V.W / CBM 切換）

#### 3.3.1 計算公式（IATA 標準）
| 指標 | 公式 | 單位 |
|------|------|------|
| **體積重（V.W）** | 長(cm) × 寬(cm) × 高(cm) × 件數 / 6000 | KG |
| **CBM（立方米）** | 長(cm) × 寬(cm) × 高(cm) × 件數 / 1,000,000 | CBM |
| **換算關係** | 1 CBM ≈ 166.67 KG（體積重） | - |

#### 3.3.2 一鍵單位切換
- 頂部導航欄設置 **VOL ⇄ CBM** 撥動開關。
- 切換時，全螢幕所有數字即時刷新（表格、ULD 容量條、匯總欄）。
- 切換開關旁帶 `ℹ️` 提示：「體積重計算標準：1 CBM = 166.67 KG」。

#### 3.3.3 ULD 容量監控儀表盤（即時進度條）
- 每個 ULD 獨立顯示：
  - **重量條**：當前毛重 / 最大限重（KG）
  - **體積條**：當前體積重或 CBM / 最大限積（依當前單位切換顯示）
- **顏色反饋**（無彈窗，僅靠顏色警示）：
  - 🟢 ≤ 85%（安全）
  - 🟠 85% ~ 98%（接近滿載）
  - 🔴 ≥ 100%（超限，ULD 邊框變紅，「確認裝載」按鈕禁用）

#### 3.3.4 貨物清單中的 V.W / CBM 展示
- 每行貨物在錄入長寬高及件數後，**自動計算並顯示**該行的 V.W / CBM。
- 若「體積重 > 毛重」，該行顯示 **「輕泡」** 標籤。

---

### 3.4 3D 場景交互與 ULD 異形處理（核心難點）

#### 3.4.1 ULD 邊框與視覺設計
| 元素 | 顏色 | 線型 | 說明 |
|------|------|------|------|
| ULD 底面外框 | 深藍 (#1a5276) | 實線 3px | 最底部承載面邊界 |
| ULD 頂部輪廓 | 橙色 (#e67e22) | 實線 2px | 最高處輪廓線 |
| 角收位斜線 | 橙紅 (#d35400) | **虛線** 2px | 區別於垂直邊界，提示此處為斜面 |
| 底面輔助網格 | 淺灰 (opacity 0.2) | 點線 | 輔助視覺定位 |

- **渲染順序**：ULD 線條始終渲染在貨物「背後/下方」，不遮擋貨物。
- **尺寸標註**：在 ULD 外部標註 L × W × H，支援 `cm` 與 `"`（英寸）即時切換。
  - **英寸符號統一使用 `"`**（如 `118"`），這是航空貨運 IT 系統的通用 ASCII 寫法。

#### 3.4.2 角收位（Contour）的幾何定義
以 **Q7-00** 為例：
- 總高度 118"
- 從 96" 高度開始，兩側向內各收 22"
- 頂部寬度 = 96" - 22" - 22" = 52"

**幾何建模要求**：
- 使用 **關鍵頂點座標集合** 定義 ULD 的 3D 異形輪廓。
- 斜面區域以**半透明橙色網格**或**虛線邊框**高亮標示。
- 提供 **「側剖面視圖」** 按鈕，一鍵切換到 ULD 側面視角，清晰展示收角輪廓。

#### 3.4.3 超限檢測與視覺提示
- **檢測邏輯**：檢查每件貨物的**所有 8 個頂點**是否都在 ULD 的異形包容體內。若有任一頂點超出，即判定為超限。
- **視覺反饋**：
  - 超限貨物 → 變為**紅色**並**紅框閃爍**
  - ULD 角收位斜線 → 變為**紅色實線**並脈衝動畫
  - 右側面板 → 出現紅色警告條，列出超限貨物 ID 及超限尺寸
  - 懸停超限貨物 → 顯示 `⚠️ 超出 ULD 輪廓限制`
  - 點擊「確認方案」時 → 彈出警告框阻止提交

---

### 3.5 自動演算法與手動編輯（人機協同）

#### 3.5.1 自動運算
- 點擊 **「智能裝箱」** 按鈕，系統基於 Hybrid GA-LNS 演算法生成 **3-5 組最優解**。
- 運算期間顯示**進度條 + 取消按鈕**，避免瀏覽器卡死。

#### 3.5.2 方案選擇與預覽
- 側邊欄以**卡片/縮略圖**形式展示多組方案，標註關鍵指標（體積利用率、重心位置、載重利用率）。
- 點擊卡片，3D 場景即時切換顯示對應方案。

#### 3.5.3 手動編輯
- **3D 場景拖拽（Drag & Drop）**：用戶可直接拖拽貨物調整位置。
  - **磁吸（Snap）效果**：靠近 ULD 邊緣或相鄰貨物時（距離 < 2cm），自動吸附對齊。
  - **碰撞檢測**：拖拽導致重疊時，貨物變為半透明紅色並彈回原位。
- **表格拖拽**：可將貨物從一個 ULD 清單拖到另一個 ULD 清單，3D 場景同步更新。
- **即時反饋**：每次手動修改後，**所有數據指標（利用率、重心、重量）即時重新計算並更新**。

---

### 3.6 組裝流程動畫（Assembly Animation）

- **觸發**：方案確認後，點擊 **「播放流程」** 按鈕。
- **播放控制條**：
  - **播放/暫停**
  - **上一步 / 下一步**（逐幀查看）
  - **速度控制**：慢速 / 正常 / 快速
  - **進度條**：顯示當前步驟（如「第 5/20 步」），滑鼠懸停可預覽該步驟縮略圖
- **視覺反饋**：
  - 當前步驟裝入的貨物 → **高亮發光邊框**
  - 資訊面板 → 同步顯示該貨物的 ID、尺寸、重量、所屬客戶
- **輔助視角**：提供**爆炸視圖**（將所有貨物從 ULD 中分離）和**分層查看**（單獨顯示某一層），方便檢查內部結構。

---

### 3.7 資訊查詢（懸停/點擊顯示貨物詳情）

> **設計目標**：操作員無需多餘點擊，0.5 秒內獲取核心資訊。

| 操作 | 觸發方式 | 顯示內容 | 顯示位置 |
|------|---------|---------|---------|
| **懸停預覽** | 滑鼠懸停貨物（無需點擊） | 貨物名稱（或客戶簡稱） + 重量(KG) + 尺寸(L×W×H) | 滑鼠旁浮動半透明標籤（毛玻璃效果），0.8 秒自動淡出 |
| **點擊鎖定** | 點擊貨物 | 完整資訊：MAWB, HAWB, Customer Name, 長寬高, 重量, PCS, 特殊備註 | 右側面板（側邊欄）鎖定顯示，點擊空白處或按 ESC 取消 |
| **透視濾鏡** | 點擊快捷欄按鈕 | `📏 顯示尺寸` / `⚖️ 顯示重量` / `📦 顯示客戶` | 所有貨物上方永久懸浮對應數據，再點一次關閉 |

- **點擊精準度優化**：將 Three.js 射線檢測（Raycaster）的碰撞體比視覺模型擴大 **5%-10%**，讓用戶不需精確瞄準邊緣。


## 四、ULD 資料庫設計（預設 + 自訂編輯器）

### 4.1 資料來源策略
- **系統預設內建** IATA 常見 ULD 型號（至少涵蓋：PMC/Q7、PGA/Q6、AKE、AKH、AAF、ALF 等），包含完整的幾何輪廓定義。
- **開發階段參考資料**：CargoGuide、IATA ULD Regulations 等公開資料庫。

### 4.2 ULD 幾何定義格式
每個 ULD 以 **「關鍵頂點座標集合」** 定義其 3D 輪廓（含收角斜面）。

**JSON 儲存範例（Q7-00）**：
```json
{
  "uld_type": "Q7-00",
  "base_length_cm": 317.5,
  "base_width_cm": 243.8,
  "height_cm": 299.7,
  "contour_type": "double_taper",
  "contour_points": [
    { "height_cm": 0, "width_cm": 243.8 },
    { "height_cm": 243.8, "width_cm": 243.8 },
    { "height_cm": 299.7, "width_cm": 132.1 }
  ],
  "max_weight_kg": 6800,
  "usable_volume_cbm": 10.8
}

### 4.3 自訂 ULD 編輯器
提供後台界面，允許用戶：

以既有 ULD 為範本複製修改（如從 Q7 複製，調整高度或收角參數）

從零建立自訂 ULD：透過輸入關鍵幾何點的座標定義輪廓（底板四角、斜面起始高度、斜面終點高度、頂板四角）

儲存為「我的 ULD 庫」，供後續專案重複使用

## 五、資料庫設計（SQLite）
### 5.1 資料表結構
projects

欄位	型別	說明
id	INTEGER	PK
mawb	TEXT	主單號
dest	TEXT	目的站
created_at	DATETIME	建立時間
ulds

欄位	型別	說明
id	INTEGER	PK
project_id	INTEGER	FK → projects.id
uld_type	TEXT	如 'Q7-00'
max_weight_kg	REAL	最大限重
contour_config	JSON	收角幾何定義（見 4.2）
status	TEXT	'pending' / 'loading' / 'completed'
customers

欄位	型別	說明
id	INTEGER	PK
project_id	INTEGER	FK → projects.id
hawb	TEXT	分單號
customer_name	TEXT	客戶名稱
color_code	TEXT	專屬色卡（如 '#3498db'）
items

欄位	型別	說明
id	INTEGER	PK
customer_id	INTEGER	FK → customers.id
assigned_uld_id	INTEGER	FK → ulds.id (nullable)
pack_type	TEXT	'PLT' 或 'CTN'
length_cm	REAL	長 (cm)
width_cm	REAL	寬 (cm)
height_cm	REAL	高 (cm)
pcs	INTEGER	件數
weight_kg	REAL	單件毛重 (KG)
is_stackable	BOOLEAN	是否可堆疊
actual_type	TEXT	備註實際形態（如 'Drum' / 'Roll'）
status	TEXT	'pending' / 'loaded'
solutions

欄位	型別	說明
id	INTEGER	PK
project_id	INTEGER	FK → projects.id
solution_data	JSON	完整裝載方案（含每件貨物的最終座標與旋轉）
utilization_rate	REAL	體積利用率
weight_utilization	REAL	載重利用率
cog_x / cog_y / cog_z	REAL	重心座標

## 七、實施路線圖（Phase 1 - 6）
